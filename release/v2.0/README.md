# Handelsvindar v2.0

## Skriv ut

Använd filerna i `print/pdf/`.

Minsta paket för spel:

1. `board-standard.pdf` eller `board-ink-friendly.pdf`
2. `trade-seal-cards.pdf`
3. `delivery-cards.pdf`
4. `markers-a4.pdf` eller egna pärlor/kuber
5. `quick-reference-a6.pdf`
6. `rulebook.pdf`

Ni behöver även papper och penna för poäng.

## Blindtest

Använd dokumenten i `docs/` för att genomföra och dokumentera ett blindtest.
