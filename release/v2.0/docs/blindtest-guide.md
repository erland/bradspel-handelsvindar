# Blindtestguide v2.0

## Syfte

Kontrollera om en grupp som aldrig tidigare sett Handelsvindar kan öppna materialet, förstå berättelsen, förbereda spelet och spela korrekt utan hjälp från konstruktören.

## Genomförande

1. Ge gruppen endast filerna i `release/v2.0/`.
2. Starta tidtagning när de öppnar regelboken.
3. Svara inte på regelfrågor under partiet.
4. Anteckna var de stannar, bläddrar tillbaka eller tolkar olika.
5. Intervjua spelarna var för sig efter partiet.

## Mätvärden

- tid till färdig förberedelse
- tid till första tur
- total speltid
- antal regeluppslag
- antal olagliga handlingar
- antal frågor om handelssigill, ledplatser och leveranser
- om spelarna kan återberätta spelets mål med egna ord
- om spelarna förstår varför efterfrågan ändrar poängen

## Viktiga observationsfrågor

- Förstår spelarna att de väljer en handling per tur?
- Förstår de att en leverans bara använder egna leder?
- Förstår de att korsande linjer inte är anslutna?
- Förstår de kostnadssiffran i en av ledplatserna?
- Förstår de att ledfärgen anger betalning och inte färdsätt?
- Upptäcker de hur slutspelet utlöses?
