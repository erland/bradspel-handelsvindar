Handelsvindar v0.8 - lokal karteditor Dra hamnarna. Exportera layoutdata när placeringen känns bra.

Arbetsflöde

Dra en hamn. Linjerna följer med. Klicka sedan på Exportera och kopiera resultatet till data/board-layout.yaml eller spara JSON som underlag.

Kurvor, etikettförskjutningar och kostnadspositioner finjusteras fortfarande i YAML.
